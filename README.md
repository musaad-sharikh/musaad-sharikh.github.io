# Bilingual Portfolio

Personal portfolio site for Musaad Muhammad, Design Engineer (Front-End & UI). English and
Arabic, hand-written and deployed on GitHub Pages.

Live: https://musaad-sharikh.github.io

**Local preview:** `python3 -m http.server 8000`

**Checks:** `node --test`
